# HDFC Bank – Power BI Dashboard Project
An interactive Power BI dashboard project that explores HDFC Bank-style deposit, loan, and branch performance data. The project is organized into three dashboard pages to make key metrics and trends easier to understand.
Note: This is a portfolio/demo project. The figures shown in the dashboards are sample or project data and should not be interpreted as official HDFC Bank financial results.

## 📊 Dashboard Pages
1. **Deposit Target Dashboard**
This page provides an overview of deposit performance and target achievement.

# Key metrics
- Total Deposit
- Deposit Target
- Achievement
- Deposit Growth

# Filters / slicers
- Year
- Quarter
- Month
- Region
- BranchID
- AccountID
- ProductCode

# Visualizations
- Deposit Target and Month comparison by Year
- Year by Quarter summary
- Year and EMI Amount comparison
- Deposit Target map by location

2. **Loan Portfolio Breakdown**
This page summarizes the loan portfolio and transaction-type distribution.

# Key metrics
- Total Loan
- Total Branch ID
- Total Quarter
- Total EMI Amount

# Filters / slicers
- ProductName
- BranchID
- Quarter
- Amount
- EMIAmmount
- Month

# Visualizations
- Amount by Transaction Type
- Amount by Quarter (donut chart)

3. **Branch Performance Dashboard**
This page focuses on branch activity and regional performance.

# Key metrics
- Total Branch ID
- Total Transaction Type
- Total Transaction ID
- Average Amount

# Filters / slicers
- Year
- Quarter
- Region
- Month
- City
- BranchID

# Visualizations
- Count of Region by City
- Deposit Target summary
- Total Branch ID by Region (donut chart)
- Month by Quarter (column chart)

## 🚀 How to Use
1. Download or clone this repository.
2. Open the .pbix file in Power BI Desktop.
3. If Power BI asks for the source data, connect it to the dataset included in the Dataset folder.
4. Select Refresh to update the report.
5. Use the slicers to explore the deposit, loan, and branch dashboards.
